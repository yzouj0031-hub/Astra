# Astra · 星屿海岛游乐园

两座岛，一个连续的 3D 世界：静屿有海浪、灯塔、营地和岛民；星辉游乐岛有摩天轮、过山车、游客和舞台。跨海栈桥连接两岛，也可以开船前往。

## 打开游玩

下载仓库并解压，用支持 WebGL 的现代浏览器打开 [`index.html`](./index.html)。场景、Three.js 和合成声音都包含在 HTML 中，核心玩法可以离线运行，不需要 API 密钥或安装依赖。

也可以在装有 Node.js 22 或更新版本的电脑上运行：

```sh
npm run dev
```

随后打开终端显示的本地地址。

## 玩法

| 操作 | 说明 |
| --- | --- |
| 静屿 / 星辉乐园 / 群岛全景 | 切换观察区域 |
| 拖动、滚轮或双指 | 环顾、缩放 |
| WASD / 方向键 | 漫步与驾驶，Shift 小跑 |
| 手机触摸 | 左侧摇杆移动，右侧拖动环顾 |
| 游乐园项目面板 | 选择项目后乘坐，结束乘坐返回地面 |
| 跨海栈桥 | 在两座岛之间双向步行 |
| 码头出海 / 靠岸 | 从游乐岛东侧码头驾船、返回登岛 |
| 钓鱼 | 抛竿 → 咬钩提竿 → 按住收线；张力高时松手，也可用空格 |
| E / 打招呼按钮 | 走近静屿的 7 位居民，挥手问候 |
| 晨光按钮 | 切换晨光、日落、星夜；夜间点亮游乐园 |
| 环境声 | 开关海浪和随距离变化的园区声音 |
| P / 明信片 | 保存当前风景 |
| 1—4 / H / R | 切换原有四种玩法 / 收起界面 / 自动环岛 |

渔获及时间偏好仅保存在当前设备的浏览器中，不会跨设备同步。

## 当前实现

- 单一 Three.js 场景、渲染器和相机，共用海面、昼夜、地图、声音开关和拍照。
- 9 种游乐设施及舞台，共 10 个乘坐或观演座位视角。
- 游客沿路线活动，设施循环运行；尚未实现完整排队上车、经营或多人联机。
- 重复模型使用实例化，静态园区模型按材质合并；手机减少游客与树木数量。
- 单文件结构方便分发；后续可以按地形、设施、角色、输入等模块拆分。

## 验证

```sh
npm test
```

检查覆盖两种屏幕尺寸下的场景初始化、岛民寻路、栈桥双向通行、10 个座位视角、退出乘坐、帆船靠岸及原有钓鱼状态变化。

检查使用内嵌的真实 Three.js 场景对象和模拟 DOM/渲染器，**不覆盖实际 GPU 着色器、浏览器画面、音频播放或设备帧率**。

## 文件
